# Ozon Viewer — 用户指南

Ozon Viewer 是一个用于管理 Ozon 和 Yandex Market 平台店铺的 Web 平台。你可以在这里跟踪价格、批量更新价格、配置自动调价（repricer），并管理价格变更历史。

**应用地址：** 你在 `BETTER_AUTH_URL` 中配置的地址（默认 http://localhost:3001）

---

# 店铺管理

## 场景：接入 Ozon 店铺

**适用场景：** 你想把自己的 Ozon 店铺接入系统。

**操作步骤：**
1. 打开 **Settings** 页面（菜单中的 ⚙️ 图标）。
2. 点击 **添加店铺** 按钮。
3. 选择平台 **Ozon**。
4. 填写以下字段：
   - **Client ID** — 在 Ozon Seller 后台 → 设置 → API 密钥中获取。
   - **API Key** — 同样在 Ozon Seller 后台中获取。
5. 点击 **保存**。

**结果：** 店铺会出现在 Settings 页面的列表中，同时出现在页头的下拉列表里。系统开始拉取商品数据。

**注意：** Client ID 和 API Key 必须从 Ozon Seller 后台（seller.ozon.ru）获取，缺少任一项都无法完成接入。

---

## 场景：接入 Yandex Market 店铺

**适用场景：** 你想把自己的 Yandex Market 店铺接入系统。

**操作步骤：**
1. 打开 **Settings** 页面（⚙️）。
2. 点击 **添加店铺**。
3. 选择平台 **Yandex Market**。
4. 填写以下字段：
   - **Business ID** — Yandex Market 后台中的业务标识。
   - **Campaign ID** — 广告系列（店铺）标识。
   - **Api-Key** — Yandex Market 后台生成的 API 密钥。
5. 点击 **保存**。

**结果：** 店铺出现在列表中，商品开始同步。

**注意：** Business ID、Campaign ID、Api-Key 三个字段都是必填项，均可在 Yandex Market 后台的 API 设置一节中找到。

---

## 场景：修改店铺配置

**适用场景：** 需要修改 API 密钥、店铺名称或其他参数。

**操作步骤：**
1. 打开 **Settings**（⚙️）。
2. 找到目标店铺的卡片。
3. 点击卡片上的 **设置** 按钮。
4. 修改需要变更的字段。
5. 点击 **保存**。

**结果：** 店铺配置已更新。若修改了 API 密钥，下一次同步将使用新密钥。

---

## 场景：删除店铺

**适用场景：** 系统中不再需要该店铺。

**操作步骤：**
1. 打开 **Settings**（⚙️）。
2. 在店铺卡片上点击 **删除**。
3. 在弹出的对话框中确认删除。

**结果：** 店铺从列表中消失。

**注意：** 该店铺的**所有**数据都会被永久删除 —— 商品、价格历史、快照、调价器配置。此操作不可撤销。

---

## 场景：在多个店铺之间切换

**适用场景：** 你有多个店铺，需要切换到另一个。

**操作步骤：**
1. 在页头（Header）找到显示当前店铺名称的下拉列表。
2. 点击展开并选择目标店铺。
3. 或者直接在侧边栏（Sidebar）中点击目标店铺。

**结果：** 商品表格、价格及所有数据都会切换到所选店铺。

---

# 价格管理 — 批量

## 场景：从 Excel 导入价格作为基准价

**适用场景：** 你想用自己表格里的「正确」价格作为基准，但暂时**不**推送到平台。例如为调价器准备价格基线。

**操作步骤：**
1. 点击 Header 中的 📥 按钮。
2. 上传含价格的 Excel 文件。
3. 系统会打开预览窗口 —— 确认货号和价格识别正确。
4. 点击 **保存基准价**。

**结果：** 价格作为 `ref_price`（基准价）保存在系统中，调价器将以此为参照。**不会**向平台推送任何数据。

**注意：** 文件中的价格仅作为基准价保存。若要真正更新平台上的价格，请使用下面的场景。

---

## 场景：导入价格并推送到平台

**适用场景：** 你既想保存基准价，又想立即更新平台上的价格。

**操作步骤：**
1. 点击 Header 中的 📥 按钮。
2. 上传 Excel 文件。
3. 在预览窗口中核对数据。
4. 点击 **基准价 + Ozon** 或 **基准价 + Yandex**（取决于店铺类型）。

**结果：** 价格既保存为基准价，又同时推送到平台。商品表格中的价格会在下一次同步后刷新。

**注意：** 导入前请确认已选中正确的店铺。价格会推送到当前激活的那个平台。

---

## 场景：解锁偏差超过 20% 的条目

**适用场景：** 从 Excel 导入价格时，部分条目被锁 🔒 住了，因为新价格与当前价格相差超过 20%。

**操作步骤：**
1. 在导入预览窗口中找到带 🔒 图标的条目。
2. 点击该条目上的锁图标。
3. 确认解锁。
4. 或点击 **全部解锁**，一次性解锁所有被锁定的条目。

**结果：** 该条目变为可更新状态，锁图标消失。

**注意：** 锁定机制是防止误操作的保护。若价格偏差超过 20%，建议先确认文件中不是笔误。

---

## 场景：从导入中排除部分条目

**适用场景：** 文件中并非所有条目都需要更新，有些想跳过。

**操作步骤：**
1. 在导入预览窗口中找到想排除的条目。
2. 取消它前面的勾选 ✅。

**结果：** 点击「保存」时该条目不会被更新，其余条目照常更新。

---

## 场景：一个 Excel 文件用于多个店铺

**适用场景：** 你有一份包含全部店铺货号的价格表，想依次导入到每个店铺。

**操作步骤：**
1. 切换到目标店铺（Header 中的下拉列表）。
2. 通过 📥 上传 Excel 文件。
3. 系统会自动匹配该店铺中存在的货号。
4. 该店铺中不存在的货号会被标记为 **「店铺中未找到」**。
5. 保存。然后对下一个店铺重复上述步骤。

**结果：** 每个店铺只会更新货号匹配上的那些条目。

**注意：** 无需为每个店铺单独准备文件。一份文件适用于所有店铺 —— 系统会自动分辨。

---

# 价格管理 — 单品

## 场景：修改单个商品的价格

**适用场景：** 需要快速修改某个商品的价格，不想走文件导入。

**操作步骤：**
1. 在商品表格中找到目标商品。
2. 点击价格旁边的 ✏️（铅笔）图标。
3. 输入新价格。
4. 点击 **保存**。

**结果：** 新价格推送到平台，表格中的价格随之更新。

---

## 场景：查看商品的价格历史

**适用场景：** 想了解某个商品的价格是如何变化的 —— 谁改的、什么时候改的、改了多少。

**操作步骤：**
1. 在商品表格中找到目标商品。
2. 点击商品旁边的 📈（图表）图标。

**结果：** 打开价格变更历史窗口：日期、原价、新价、变更来源。

---

# 调价器

## 场景：启用调价器

**适用场景：** 你希望系统在价格偏离基准价时自动纠正。

**操作步骤：**
1. 先从 Excel 导入基准价（见场景「从 Excel 导入价格作为基准价」）。
2. 打开 **Settings**（⚙️）。
3. 在目标店铺卡片上点击 **设置**。
4. 打开 **调价器** 开关。
5. 设置参数：
   - **检查间隔** —— 多久检查一次价格（默认 15 分钟）。
   - **偏差阈值** —— 偏离基准价多少时进行纠正（默认 5%）。
6. 点击 **保存**。

**结果：** 调价器开始在后台运行。若平台上的价格偏离基准价超过设定阈值，系统会自动把它拉回基准价。

**注意：** 没有导入基准价，调价器就没有对比基线 —— 它不会工作。请先导入基准价。

---

## 场景：确认调价器正在运行

**适用场景：** 想确认调价器确实在启动并执行检查。

**操作步骤：**
1. 点击 Header 中的 🔄 按钮。
2. 打开调价器的运行批次日志。

**结果：** 表格中列出所有运行批次：日期、时间、检查的商品数量、被纠正的价格数量。

---

## 场景：查看调价器改了什么

**适用场景：** 想了解调价器具体纠正了哪些价格、原因是什么。

**操作步骤：**
1. 点击 Header 中的 🔄 按钮。
2. 使用 **已纠正** 筛选器。

**结果：** 表格中列出发生纠正的商品：商品名称、纠正前价格、纠正后价格、纠正原因。

---

## 场景：回滚调价器的改动

**适用场景：** 调价器改动了价格，但你想恢复到之前的价格。

**操作步骤：**
1. 点击 Header 中的 📋 按钮（快照历史）。
2. 切换到 **Repricer** 标签页。
3. 按日期找到目标快照。
4. 点击 **回滚**。
5. 确认操作。

**结果：** 价格恢复到调价器改动前的状态，新价格会推送到平台。

---

# 历史与回滚

## 场景：对比变更前后的价格

**适用场景：** 想查看价格导入或调价器运行后发生了哪些变化。

**操作步骤：**
1. 点击 Header 中的 📋 按钮。
2. 在列表中找到目标快照。
3. 点击 **对比**。

**结果：** 打开对比表格：商品、变更前价格、变更后价格、百分比差异。

---

## 场景：回滚到之前的价格

**适用场景：** 出了问题，需要把价格恢复到更早的状态。

**操作步骤：**
1. 点击 Header 中的 📋 按钮。
2. 按日期和描述找到目标快照。
3. 点击 **回滚**。
4. 确认操作。

**结果：** 当前价格被所选快照中的价格覆盖，更新后的价格推送到平台。

**注意：** 回滚会覆盖当前价格。执行前请确认选对了快照。

---

## 场景：区分人工改动与调价器改动

**适用场景：** 想弄清楚哪些改动是人工做的，哪些是调价器自动做的。

**操作步骤：**
1. 点击 Header 中的 📋 按钮。
2. 你会看到两个标签页：
   - **人工改动** —— 人工导入与人工编辑后产生的快照。
   - **Repricer** —— 自动纠正后产生的快照。
3. 在两个标签页之间切换查看。

**结果：** 人工改动与自动改动的历史分开呈现。

**注意：** 每种类型只保留最近 10 个快照，更早的快照会被自动删除。

---

# 监控

## 场景：查看告警

**适用场景：** 想知道商品是否存在问题。

**操作步骤：**
1. 打开商品表格。
2. 查看表格上方的彩色标签：
   - **红色** —— 严重问题（价格隔离、商品不可见）。
   - **黄色** —— 警告（价格不一致、参与促销活动）。
3. 点击标签。

**结果：** 表格会自动筛选，只显示存在该问题的商品。

---

## 场景：按问题类型筛选

**适用场景：** 想快速找出存在某个具体问题的商品。

**操作步骤：**
1. 在商品表格上方找到筛选按钮：
   - **价格隔离** —— 在平台上处于价格隔离状态的商品。
   - **价格≠** —— 平台价格与基准价不一致。
   - **促销活动** —— 正在参与促销活动的商品。
   - **不可见** —— 未在前台展示的商品。
2. 点击需要的按钮。

**结果：** 表格只显示存在该问题的商品。

---

## 场景：查看 API 日志

**适用场景：** 出现异常时，需要弄清楚系统向平台发送了哪些请求、返回了什么。

**操作步骤：**
1. 点击 Header 中的 📡 按钮。
2. 使用筛选条件：
   - **来源** —— 请求来自哪里（人工、调价器、同步）。
   - **状态** —— 成功或失败。
   - **时间段** —— 显示哪个时间范围的日志。

**结果：** 表格列出所有发往平台 API 的请求：时间、类型、状态、详情。

---

## 场景：手动触发同步

**适用场景：** 想立刻从平台拉取最新数据，不等待自动同步。

**操作步骤：**
1. 打开 **Settings**（⚙️）。
2. 在目标店铺卡片上点击 **Sync Now**。

**结果：** 系统向平台请求最新数据，几分钟后商品表格会刷新。

**注意：** 同步也会按计划自动执行。只有想立刻看到变化时才需要手动触发。

---

## 场景：导出到 Excel

**适用场景：** 需要把商品和价格数据下载成文件。

**操作步骤：**
1. 打开目标店铺的商品表格。
2. 点击表格上方的 **导出** 按钮。

**结果：** 下载一个 Excel 文件，包含当前店铺的全部商品：货号、名称、价格、状态。

# 批量编辑

## 场景：用公式批量调价

**适用场景：** 需要按公式修改价格 —— 例如全部上调 10%。

**操作步骤：**
1. 打开 **Mass Edit** 页面。
2. 输入公式，例如：`price * 1.1`（上调 10%）。
3. 点击 **预览** —— 系统会展示哪些价格会变、变成多少。
4. 核对结果。
5. 点击 **提交**。

**结果：** 价格按公式重新计算并推送到平台。

**注意：** 提交前务必查看预览。公式会作用于该店铺的全部商品。

---

## 场景：设定定时调价

**适用场景：** 希望价格在指定时间更新 —— 例如促销活动开始前。

**操作步骤：**
1. 打开 **Mass Edit** 页面。
2. 设置好要执行的变更（公式或文件导入）。
3. 点击 **定时执行**。
4. 选择日期和时间。
5. 确认。

**结果：** 任务已保存。到指定时间价格会自动更新。

---

## 场景：取消定时调价

**适用场景：** 改变主意了，需要取消已排定的价格更新。

**操作步骤：**
1. 打开 **Dashboard** 页面（如果可用）或 **Settings**。
2. 找到已排定的任务。
3. 点击 **取消**。

**结果：** 定时更新被删除，价格保持不变。

---

# 用户管理

## 场景：添加用户

**适用场景：** 需要为其他人开通系统访问权限。

**操作步骤：**
1. 打开 **Settings**（⚙️）。
2. 进入 **用户** 一节（仅管理员可见）。
3. 点击 **添加用户**。
4. 填写字段：
   - **Email** —— 电子邮箱地址。
   - **密码** —— 登录密码。
   - **角色** —— 选择一个或多个角色。
5. 点击 **保存**。

**结果：** 该用户可以用指定的邮箱和密码登录系统。

**注意：** 「用户」一节仅管理员可见。

---

## 场景：角色与权限

**适用场景：** 想弄清楚谁在系统里能做什么。

**操作步骤：**
1. 创建或编辑用户时选择角色：
   - **admin** —— 拥有全部功能的完整权限。
   - **repricer** —— 商品与价格权限（查看、编辑、导入）。

**结果：** 用户只能看到其角色允许的板块和按钮。

**注意：** `admin` 角色包含全部权限。`repricer` 角色的用户可以访问商品与价格，但不能管理用户。
